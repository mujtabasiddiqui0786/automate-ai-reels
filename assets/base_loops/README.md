# Base Loops Directory

This directory should contain your base video clips that will be used to generate satisfying loop videos.

## Requirements

### File Format
- **Supported formats**: MP4, MOV, AVI, MKV, WebM
- **Recommended**: MP4 (H.264 codec) for best compatibility
- **Aspect ratio**: Any (will be cropped/resized to 9:16)
- **Duration**: Any (will be looped to match target duration)
- **Resolution**: Any (will be resized to 1080x1920)

### Video Content
- Videos should be suitable for looping (seamless start/end)
- Content should work well with color adjustments, speed changes, and mirroring
- Examples: smooth animations, flowing liquids, rotating objects, geometric patterns

### Naming
- Use descriptive filenames (e.g., `smooth_gradient_loop.mp4`, `water_flow.mp4`)
- Avoid special characters in filenames
- The system will randomly select from available videos based on seed

## Adding Videos

1. Place your video files directly in this directory
2. Ensure videos are in a supported format
3. Restart the server if it's running to pick up new files

## Tips

- **Seamless loops**: Videos that loop seamlessly will create the best results
- **High quality**: Start with high-quality source videos for best output
- **Variety**: Add multiple different styles of loops for variety
- **File size**: Keep files reasonably sized (under 100MB recommended)

## Example Workflow

1. Create or download satisfying loop videos
2. Place them in this directory
3. The system will automatically select and transform them when generating new videos
